# Audit UI/UX — 8 octobre 2026

Grille : [Audit UI/UX](../audit-ui-ux.md). Procédure : skill `audit-ux`. Les bloquants sont
corrigés dans la même PR que ce rapport ; le reste est planifié dans la
[roadmap](../roadmap.md#plan-uiux-et-fonctionnalités-octobre-2026).

## Ce qui a été passé

| Plateforme | Couverture |
|---|---|
| App web | 22 écrans × clair/sombre × mobile (Pixel 7) et desktop (1280 px), en français et en néerlandais ; tous les écrans à 320 px ; axe (WCAG 2.2 AA) en clair et en sombre sur 15 pages |
| Site vitrine | `/`, `/en/`, `/nl/` à 360 et 1440 px, clair et sombre ; rendu sans JavaScript ; débordement horizontal mesuré |
| Android | captures Roborazzi (Aujourd'hui, Tâches, Calendrier, Courses, formulaire, Réglages, hors ligne sombre) ; lint |
| Transverse | contraste WCAG calculé sur tous les tokens (texte, UI, couleurs de membres) ; clés de traduction (web : 0 manquante ; Android : 0 hors `app_name` et URL) |

Outils ajoutés pour les audits suivants : `VISUAL_LOCALE=en|nl` dans `e2e/visual-review.spec.ts`
(captures dans une autre langue), `playwright.narrow.config.ts` (320 px), et les pages Dépenses,
Menus, Plus et Revue dans les captures et dans l'audit axe.

## Constats

Gravité : **B** bloquant (empêche la fusion), **A** à améliorer. Effort : S (< 1 h), M (une
demi-journée), L (plusieurs jours).

## Ce qui n'a pas été vérifié

- TalkBack et les réglages Android réels (police système 200 %, mode avion) : pas d'appareil.
- Lighthouse : pas lancé dans le conteneur.
- Ordre du focus au clavier : couvert par axe (pas de violation), pas parcouru touche par touche.
