# Dépenses

**Dépenses** (menu de gauche sur ordinateur ; **Plus → Dépenses** sur téléphone ; dans l'app
Android, **Réglages → Dépenses**) : on note ce qu'on paie pour le foyer, et Tandem calcule qui
doit combien à qui.

## Ajouter une dépense

**+ Dépense**, puis :

- **Montant** (par exemple `12,50`), **date**, **quoi** (« Courses », « Loyer »…) ;
- **Payé par** : qui a sorti la carte ;
- **Pour qui ?**
  - **Commune** : partagée selon les proportions du foyer (moitié-moitié par défaut) ;
  - **Pour Nicolas** : vous avez avancé pour l'autre, qui en doit la totalité ;
  - **Perso** : pour vous seul ; **visible de vous seul**, elle n'entre pas dans le calcul
    commun mais compte dans « Mes dépenses personnelles » ;
- **catégorie** (courses, logement, énergie, transport, loisirs, santé, enfants, cadeaux…) et
  un **commentaire** facultatif.

Toucher une dépense permet de la modifier ou de la supprimer.

## Qui doit quoi

En haut de la page : « **Nicolas doit 42,50 € à Grace** », calculé depuis la première dépense.
Quand c'est réglé (virement, espèces…), **Enregistrer le remboursement** : le solde revient à
zéro. Un remboursement enregistré par erreur se supprime comme une dépense.

À plus de deux, Tandem propose le moins de remboursements possible pour tout équilibrer.

## Les totaux du mois

- **Dépenses communes** du mois ;
- pour chacun : **ce qu'il a payé** et **sa part** des dépenses communes ;
- **mes dépenses personnelles** (et celles avancées pour moi) ;
- **par catégorie** (à déplier).

Les flèches changent de mois.

## Partage 60 / 40

**Partage 50 / 50** (au-dessus du solde, sur le site) règle les proportions des dépenses
communes, par exemple 60 / 40 selon les revenus. Les dépenses **déjà enregistrées gardent leur
partage** : changer les proportions ne réécrit pas le passé.

## Bon à savoir

- Montants en euros, au centime près : la somme des parts vaut toujours le montant (un centime
  impair va à l'un des deux).
- Tout le foyer voit les dépenses communes et les avances ; une dépense perso n'est visible que
  de la personne qui l'a payée.
- Les dépenses font partie de l'**export de vos données** (Réglages → Données & confidentialité).
  À la suppression d'un compte, ses dépenses perso sont effacées ; les dépenses communes restent
  pour que les soldes de l'autre restent justes, au nom d'« Ancien membre ».
- Sur Android, les dépenses demandent une connexion ; les proportions se règlent sur le site.
