# Hors ligne

Le site comme l'app Android restent utilisables **sans réseau** (métro, cave, supermarché).

| Sans réseau | Site | App Android |
|---|---|---|
| Consulter les tâches déjà affichées, les courses | ✓ | ✓ |
| Cocher une tâche, un article de courses | ✓ | ✓ |
| Ajout rapide, ajouter des courses | ✓ | ✓ |
| Créer ou modifier une tâche en détail, reporter | — | ✓ |
| Sous-tâches, pièces jointes, modèles, réglages | — | — |

Un bandeau indique le mode hors ligne et le nombre de **modifications en attente**. Au retour du
réseau, elles sont envoyées dans l'ordre, **sans doublon** (même si l'envoi est interrompu et
recommencé). Si l'autre a modifié la même tâche entre-temps, sa version est conservée et vous le
voyez.

La copie locale est effacée à la déconnexion.
