# Aide et signalement

1. **Le site ne répond pas ?** Regardez d'abord [l'état du service](https://agenda.fs0ciety.org/status) :
   un incident en cours y est affiché, l'administrateur est déjà prévenu automatiquement.
2. **Une question ?** Les [questions fréquentes](faq.md) couvrent les cas courants.
3. **Un bug, une idée ?** Contactez l'administrateur du foyer, en précisant :
   - ce que vous faisiez, ce qui s'est passé et ce que vous attendiez ;
   - sur quoi (site ou app Android, navigateur, version de l'app : Réglages → Compte) ;
   - l'heure approximative (pour retrouver l'erreur dans les journaux).

Les erreurs techniques du site et de l'app sont déjà remontées automatiquement, sans contenu de
tâche ni identité : le signalement sert surtout à décrire le contexte.
