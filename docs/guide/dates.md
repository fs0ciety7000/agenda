# Dates importantes

L'anniversaire de mamie, celui de votre mariage, l'entretien de la chaudière ou le contrôle
technique : notez-les une fois dans **Dates importantes**, Tandem vous prévient tous les deux à
l'avance. Sur téléphone, **Plus → Dates importantes** ; sur ordinateur, **Dates** dans le menu.

- **Nouvelle date** : un titre, un type (anniversaire, fête, entretien, autre), le jour et le
  mois. L'**année** est facultative pour une date qui revient chaque année : indiquée, elle
  affiche l'âge (« 76 ans ») ou le nombre d'années.
- **Chaque année** est coché par défaut. Décoché, la date ne sert qu'une fois : l'année est alors
  obligatoire, et la date passe en « Passée » ensuite.
- **Rappel** : le jour même, la veille, ou 3, 7, 14 ou 30 jours avant (7 par défaut). Le rappel
  arrive à **tout le foyer**, dans la cloche et en notification, à partir de 8 h (heure du foyer),
  une seule fois par occurrence. Il se règle dans **Réglages → Notifications** (« Date importante
  qui approche »).
- La liste montre les dates **les plus proches d'abord** : « mardi 13 octobre · dans 5 jours ·
  76 ans ».
- Sur **Aujourd'hui**, la rubrique **Bientôt** affiche les dates des deux semaines à venir.
- Un 29 février tombe le 28 les années non bissextiles.

Chacun peut ajouter, modifier ou supprimer les dates du foyer. Elles demandent une connexion
pour être modifiées. Une date peut concerner un proche (un anniversaire) : elle reste une
donnée du foyer et figure dans l'export de vos données.
