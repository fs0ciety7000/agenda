# Notes partagées

Le code Wi-Fi, la taille des fenêtres du salon, les idées cadeaux de l'anniversaire qui
approche : tout ce qu'on se redemande trouve sa place dans **Notes**. Sur téléphone, l'onglet
**Plus → Notes** ; sur ordinateur, **Notes** dans le menu.

- **Nouvelle note** : un titre, un contenu (jusqu'à 4 000 caractères, retours à la ligne
  compris), et la case **Épingler en haut** pour la garder en tête de liste.
- **Épingler** se fait aussi d'un geste depuis la liste (punaise sur le site, étoile sur
  Android). Les notes épinglées passent d'abord, puis les plus récemment modifiées.
- **Copier** met le contenu dans le presse-papiers : pratique pour coller un code Wi-Fi.
- **Chacun peut modifier ou supprimer** toutes les notes du foyer. Chaque note indique qui l'a
  modifiée en dernier, et quand. Une note supprimée par erreur se récupère avec **Annuler**, juste
  après (sur le site).
- **Modifiée par l'autre en même temps** : l'enregistrement s'arrête, la dernière version
  s'affiche avec un message ; vérifiez, puis enregistrez à nouveau. Rien n'est écrasé sans le
  savoir.
- Les notes se mettent à jour **en direct** chez l'autre. Elles demandent une connexion pour
  être modifiées (hors ligne, le site les affiche en lecture).

Les notes sont des données du foyer : elles restent après la suppression d'un compte (l'auteur
devient « ancien membre ») et figurent dans l'export de vos données (**Réglages → Données &
confidentialité**).
